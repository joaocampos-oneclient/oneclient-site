# UI Kit — Marketing

Pixel-feel marketing site for OneClient. Hero, verticals, platform, quote, pricing, footer.

- `index.html` — standalone entry; uses React via CDN and Babel for inline JSX.
- `styles.css` — all component styles. Imports `colors_and_type.css` tokens.
- `Nav.jsx`, `Sections.jsx` — component snapshots for extraction into other projects.

This kit is a *visual* recreation. Interactions are stubbed. Drop into a real Next.js app by extracting the JSX and the styles.
